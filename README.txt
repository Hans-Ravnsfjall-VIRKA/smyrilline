Tollroknari offline app

1. Upload this whole folder to any https host (Netlify Drop: app.netlify.com/drop, or GitHub Pages).
2. On the iPad open the address in Safari while online.
3. Share > Add to Home Screen.
4. Open it once from the Home Screen icon while online, then it works in airplane mode.

To update: replace index.html on the host and change VERSION in sw.js (for example tollroknari-v5 to tollroknari-v6).
Open the app once online and it picks up the new copy.
